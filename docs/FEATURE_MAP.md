# Feature map — course coverage contract

**Status: Phase 1 plan, 2026-10-27 (America/Chicago).** Each row is an example-sized lesson. All named features in that row must be taught, exercised and tested. Links into modules describe planned files; they become valid as the approved phases are implemented. No lesson is claimed complete yet.

The full inventory is [course-plan.json](course-plan.json); the [final tree](REPOSITORY_TREE.md) contains every planned target. Each module has three separately runnable exercises and solutions, a use case, a cleared notebook and tests. Closely related features share a small example; a lesson exceeding about 120 lines will be split and this contract updated.

MCP uses the documented replacement described in [verification notes](VERIFICATION_NOTES.md). The retired client is explained in the migration guide, not silently substituted. Advanced retrieval is implemented from current primitives rather than depending on older chain helpers.
