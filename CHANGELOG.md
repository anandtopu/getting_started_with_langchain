# Changelog

## 0.6.0 — 2026-10-28

- Added modules 14–17: 28 orchestration examples, four applications, 12 exercise starters and solutions, quizzes and four mirrored notebooks.
- Added an explicit return graph with durable review, transactional eligibility rechecks, reviewed-amount validation, and an idempotent local notification outbox.
- Added dynamic category workers, bounded report revision, restricted specialists and minimum-context delegation.
- Added manual research planning, confined virtual files, source validation, opt-in Tavily integration and a verified optional Deep Agents SDK example.
- Added Operations Desk with eight contract cases, a measured report and written design rationale.
- Verified the local LangGraph CLI server with a real localhost graph request; Studio browser, live providers, Tavily service and remote CI remain unverified.
- Three modules and the capstones remain planned for Phases 7–8.

## 0.5.0 — 2026-10-28

- Added modules 10–13: 28 examples, four applications plus a local inventory server, 12 exercise starters and solutions, quizzes and four mirrored notebooks.
- Added transactional synthetic returns with ownership, warehouse eligibility, exact approval thresholds, idempotency and quantity checks.
- Added Guarded Support with eight scripted contract cases and a measured pause/write report; reviewer decisions are explicitly simulated.
- Added SQLite checkpoints, durable customer preferences and current middleware demonstrations.
- Verified official-SDK MCP exchanges over memory, stdio and in-process Streamable HTTP handlers with the current beta adapter.
- Updated pypdf to verified patch 6.21.4 and extended optional-tier checks.
- Seven modules remain planned. Live model quality, remote MCP deployment and remote CI remain unverified.

## 0.4.0 — 2026-10-28

- Added modules 06–09: 27 retrieval examples, four applications, 12 exercise starters and solutions, quizzes and four source-matched notebooks.
- Added Handbook Q&A with page-aware retrieval, validated quotes, six evaluation cases, a committed offline report and acceptance tests.
- Added current loader adapters, chunk provenance, embedding cache isolation, persistent Chroma manifests, hybrid ranking, exact-extract compression and bounded query rewriting.
- Recorded a reproducible before/after benchmark: 138 to 44 chunks with unchanged source/page hit rate of 5/7. No live quality improvement is claimed.
- Removed the sunset community integration package; PDF/CSV/JSON/text ingestion now uses the core loader interface, pypdf and standard-library readers.
- Extended the glossary and troubleshooting guide, and made basic-installation tests explicitly skip unavailable retrieval extras.
- Eleven modules remain planned. Live provider generation and remote CI remain unverified.
